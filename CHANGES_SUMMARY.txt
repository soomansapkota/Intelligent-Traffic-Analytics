MODEL TRAINING METHODOLOGY
================================================================================

PROPOSED:
  • Model type: Ridge or XGBoost (unspecified)
  • Validation: Risky - mentions temporal leakage risks
  • Evaluation: Generic "MAE/RMSE/MAPE"

IMPLEMENTED:
  • Model type: HistGradientBoostingRegressor (3 independent models)
  • Horizons: Separate model for 5-min, 10-min, 15-min predictions
  • Validation: Chronological split (80% past data, 20% future data)
  • Prevents: Temporal leakage - future data never influences past training
  • Evaluation Metrics:
    - MAE: Mean absolute error (seconds of delay)
    - RMSE: Root mean squared error (penalizes outliers)
    - R² Score: Variance explained vs baseline
    - Baseline: Persistence model (naive "delay now = delay in 5min")
  • Result: PENDING — models/ contains no trained .pkl files yet and the
    MAE/RMSE/R² table in the report is unfilled. Run `python -m src.modeling.train`
    and record the real numbers before claiming the models beat the baseline.
